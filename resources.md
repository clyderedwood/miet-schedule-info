## Поддержка

Для сообщения об ошибке подготовьте:

- страницу или канал, где возникла проблема;
- тип расписания: группа, преподаватель или аудитория;
- дату и пример ожидаемого результата;
- фактический результат;
- время возникновения проблемы и часовой пояс;
- для API — endpoint, HTTP status и безопасный фрагмент ответа без токена.

Не отправляйте API-токены, cookies, session identifiers, приватные ссылки на экспорт и другие секреты.


## Статус и актуальность данных

Пользовательские предупреждения отображаются в интерфейсах сервиса. API-клиенты могут использовать `/api/v1/status`, `/api/v1/data-status` и metadata ответов в соответствии с доступными abilities.

## Условия использования данных

Сервис не является официальным сервисом МИЭТ. Данные предоставляются для информационного использования и могут обновляться с задержкой. Для критически важных решений сверяйте информацию с официальными источниками.
