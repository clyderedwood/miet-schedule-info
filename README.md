# Публичная документация расписания МИЭТ

Сервис помогает находить расписание групп, преподавателей и аудиторий МИЭТ. Расписание доступно на сайте, в устанавливаемом PWA, через Telegram-бота и read-only API.

Проект не является официальным сервисом МИЭТ. Перед важным событием сверяйте актуальность данных и предупреждения, показанные сервисом.

## Быстрый старт

1. Откройте [главную страницу](/).
2. Найдите группу, преподавателя или аудиторию.
3. Перейдите к расписанию выбранной сущности.
4. При необходимости установите [PWA](/pwa) или используйте Telegram-бота.

## Что можно сделать

- посмотреть расписание группы, преподавателя или аудитории;
- узнать текущую и следующую пару;
- найти свободную аудиторию;
- сохранить избранное в PWA;
- экспортировать расписание в XLSX;
- получать расписание и изменения через read-only API;
- использовать Telegram для расписания, избранного, подписок и дайджестов.

## Важные ограничения

- Доступность и актуальность обновлений зависят от источника расписания.
- Offline-режим PWA работает только с ранее открытыми или сохранёнными страницами и ресурсами.
- Публичный API предназначен только для чтения данных.
- Отдельные API-разделы могут быть временно недоступны.
