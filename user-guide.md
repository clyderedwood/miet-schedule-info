# Пользовательские сценарии

## Найти расписание группы

1. Откройте раздел [«Группы»](/groups).
2. Найдите нужную группу в каталоге или через поиск.
3. Откройте страницу группы.
4. Выберите нужный день или неделю в доступном интерфейсе.

Название группы в адресе страницы может быть представлено в URL-кодировке. Для переходов используйте ссылки, сформированные сайтом.

## Найти расписание преподавателя

1. Откройте раздел [«Преподаватели»](/teachers).
2. Выберите преподавателя из каталога или результатов поиска.
3. Откройте расписание и нужный период.

Если встречаются однофамильцы, ориентируйтесь на полное имя в результатах.

## Найти расписание аудитории

1. Откройте раздел [«Аудитории»](/rooms).
2. Найдите помещение по его обозначению.
3. Перейдите на страницу аудитории.

Сервис может приводить разные варианты обозначения одной аудитории к единому названию.

## Найти свободную аудиторию

Откройте страницу [свободных аудиторий](/rooms/free). Используйте доступные фильтры даты, пары и названия помещения. Результат отражает данные расписания на выбранный момент и не является гарантией фактической доступности помещения.

## Узнать текущую или следующую пару

На страницах расписания и в поддерживаемых каналах сервис может показывать текущую и следующую пару. Расчёт времени выполняется для часового пояса `Europe/Moscow`.

## Экспортировать расписание

1. Откройте [экспорт расписания](/export).
2. Выберите доступный тип расписания и нужную сущность.
3. Задайте период, если интерфейс предлагает выбор.
4. Запустите экспорт.
5. При фоновой генерации дождитесь готовности файла и скачайте XLSX.

Не передавайте другим пользователям ссылку на незавершённый или персонально сформированный экспорт без необходимости.

## Использовать общий поиск

Поиск на сайте и в PWA помогает находить группы, преподавателей и аудитории. Для более точного результата вводите полное или достаточно различимое название.

## Проверить актуальность

Обращайте внимание на предупреждения об обновлении или возможной неактуальности расписания. Дата обновления также доступна в API metadata и статусных ответах.
